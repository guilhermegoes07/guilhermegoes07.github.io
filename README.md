## Descrição

O objetivo principal deste projeto foi aplicar e consolidar conhecimentos em desenvolvimento front-end, servindo como um laboratório prático para as tecnologias listadas abaixo. Trata-se de uma aplicação simples, construída com foco em componentização, estilização e a estrutura de um projeto Next.js.

## Pilha de Tecnologias (Tech Stack)

As seguintes tecnologias foram utilizadas na construção do projeto:

* **Framework**: Next.js
* **Biblioteca UI**: React
* **Linguagem**: JavaScript
* **Estilização**: Tailwind CSS
* **Hospedagem**: GitHub Pages

## Instalação e Execução Local

Para executar o projeto em um ambiente de desenvolvimento local, siga as instruções abaixo. É necessário ter Node.js e npm (ou Yarn) instalados.

1.  **Clone o repositório:**
    ```sh
    git clone [https://github.com/guilhermegoes07/guilhermegoes07.github.io.git](https://github.com/guilhermegoes07/guilhermegoes07.github.io.git)
    ```

2.  **Navegue até o diretório do projeto:**
    ```sh
    cd guilhermegoes07.github.io
    ```

3.  **Instale as dependências do projeto:**
    ```sh
    npm install
    ```

4.  **Inicie o servidor de desenvolvimento:**
    ```sh
    npm run dev
    ```

5.  A aplicação estará disponível em `http://localhost:3000`.
